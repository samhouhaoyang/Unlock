# Separate private attempts from approved teaching copies

Accepted for [product v2](../../product.md). A private attempt, a learner-previewed help request with selected context, and an independently approved teaching copy are separate records and permissions. A raw transcript, unreviewed AI output, or private attempt cannot automatically become shared advice. The approved copy carries a cue, principle, applicability, exception, review status, and source. Feedback reveals it only after submission.

P0 uses pre-reviewed fictional cards, a validated local mentor lesson import, and local VS Code state. Local import does not authenticate the declared reviewer. The extension may read a junior-previewed editor selection for unscored help but does not persist or upload raw code. It demonstrates the content boundary without a live mentor service or multi-user isolation. A future company deployment must implement actual access control and approval before sharing. See [implementation decisions](../implementation-decisions.md).
