# Separate private attempts from published experience

Accepted in [product v1.3](../../product.md), sections 7, 12, and 15. A private attempt, the learner's previewed help request, and the mentor's published experience card are distinct information boundaries: publication creates an approved shared content copy rather than exposing the source transcript. Reusing a live link to private context would simplify data handling but would make later sharing and deletion behavior depend on material the learner never approved for publication.

Shared feedback contains the reviewed explanation, attribution, and applicability limits; provenance must not grant other learners access to private attempts or help requests. The local demo illustrates this workflow through one browser and does not establish real multi-user isolation.
